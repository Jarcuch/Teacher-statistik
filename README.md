# Teacher_statistik

Aplikace vychází z verze Partner Statistik 2.5. Pro nasazení na GitHub Pages rozbalte ZIP a nahrajte všech sedm souborů do kořene samostatného repozitáře.

Teacher_statistik má vlastní úložiště v prohlížeči a otevírá se přímo na přehledu. Pokud chcete přenést stávající záznamy, vyexportujte zálohu v původní aplikaci a importujte ji v Teacher_statistik přes Nastavení → Importovat data (JSON). Zálohu uchovávejte v soukromí.

Černé logo na bílém pozadí je v záhlaví aplikace a v instalačních ikonách.
