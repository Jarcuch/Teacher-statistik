# Teacher_statistik

Aplikace vychází z verze Partner Statistik 2.5. Pro nasazení na GitHub Pages rozbalte ZIP a nahrajte všechny soubory do kořene samostatného repozitáře.

Teacher_statistik má vlastní úložiště v prohlížeči. Náslechové záznamy i kontrolní činnost se ukládají v tomto zařízení; export/import v Nastavení přenáší učitele, kritéria a všechny záznamy. Zálohu uchovávejte v soukromí.

Bílé logo ve tvaru štítu je v záhlaví aplikace. Fialový štít s průhledným okolím se používá jako ikona při přidání na plochu.
