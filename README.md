# Teacher_statistik

Aplikace vychází z verze Partner Statistik 2.5. Pro nasazení na GitHub Pages rozbalte ZIP a nahrajte všech sedm souborů do kořene samostatného repozitáře.

Teacher_statistik má vlastní úložiště v prohlížeči. Hospitační i kontrolní činnost se ukládají v tomto zařízení; export/import v Nastavení přenáší učitele, kritéria a všechny záznamy. Zálohu uchovávejte v soukromí.

Černé logo na bílém pozadí je v záhlaví aplikace a v instalačních ikonách.
